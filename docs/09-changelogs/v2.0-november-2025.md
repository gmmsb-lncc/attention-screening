# DockTKinase v2.0 - November 2025

## Major Release: Multi-Model Protein Embeddings

This release introduces support for multiple protein embedding models, with **Boltz-2** as the flagship addition, alongside comprehensive architecture improvements and production-ready features.

## 🆕 New Features

### Boltz-2 Integration
- **Structure + Affinity Prediction**: First integration of Boltz-2 biomolecular foundation model
- **384-dim Single Representation**: Default mean-pooled token embeddings
- **1024-dim Multi-Pooling**: Optional CLS + Mean + Max pooling strategy
- **CLI-based Strategy**: Efficient subprocess wrapper with error handling
- **GPU Acceleration**: Automatic CUDA/MPS device detection
- **MSA Support**: Optional ColabFold server integration

### Architecture Enhancements
- **Strategy Pattern**: Unified interface for all protein models (Boltz, ESM)
- **Factory Pattern**: `ProteinModelFactory` for easy model instantiation
- **Model Registry**: Centralized configuration in `model_registry.py` and `constants.py`
- **CLI Strategies**: Support for CLI-based models alongside HuggingFace models

### Dependency Management
- **Auto-Installation**: Complete dependency installer via `post_install.py`
- **FM4M Dependencies**: Added `torch_nl`, `ase`, `torch-scatter`
- **Boltz Dependencies**: `einx`, `fairscale`, `hydra-core`, `mashumaro`, etc.

## 🔧 Improvements

- **298/299 Success Rate**: Validated on kinase_non_human_compounds dataset

### Code Quality
- **Conditional Loading**: Proper handling of CLI vs HuggingFace models
- **Error Handling**: Robust validation and informative error messages

## 🚀 Migration Guide

### For Existing Users

No changes required! The default behavior remains unchanged. To use Boltz-2:

```bash
# CLI
python run_complete_pipeline.py \
    --input data.tsv \
    --output results/ \
    --esm-model boltz2

# Python API
config = IntegratedConfig(
    ...,
    esm_model="boltz2"
)
```

### For Developers

If extending the codebase, note the new Strategy pattern:

```python
from src.build.embeddings.strategies.base_protein_strategy import BaseProteinStrategy

class MyStrategy(BaseProteinStrategy):
    def load(self, model_name, device, **kwargs):
        # Return (model, tokenizer) or (None, None) for CLI
        pass
    
    def generate(self, model, tokenizer, sequence, device, **kwargs):
        # Return np.ndarray embedding
        pass
```
