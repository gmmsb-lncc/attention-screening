# Methodological references

Permanent copies of papers used as methodological standards in this project.

| File | Authors / venue | Role |
|---|---|---|
| `ash_wognum_2025_jcim.pdf` | Ash, Wognum, Rodríguez-Pérez, Aldeghi, Cheng, Clevert, Engkvist, Fang, Price, Hughes-Oliver, Walters · *J. Chem. Inf. Model.* 2025, 65:9398–9411 (DOI 10.1021/acs.jcim.5c01609) | **Primary statistical comparison standard** for this thesis. Defines the 4 guidelines (performance sampling distribution, statistical significance, practical significance, presentation) used in `docs/01-methodology/statistical_protocol.md`. Referenced as Ash/Wognum 2025 throughout. |

When citing the standard in code, docs, or commit messages, use the short form `Ash/Wognum 2025` and link to this directory.

The companion open-source implementation lives at `polaris-hub/polaris-method-comparison` on GitHub.
